청소년 노동인권 10차시 (1차시 50분) · 웹 배포용 자료
==================================================

배포할 파일 (이 두 개만 올리면 됩니다)
  index.html        수업자료 전체 (개요, 1~10차시, 교사 운영 안내, OX 퀴즈 100문항, 임금 계산기, 학습지)
  학습지모음.html    10차시 학습지 인쇄용 (정답 표시 토글, 전체 인쇄)

사용법
  - 파일을 브라우저에서 열거나 학교 홈페이지·LMS·구글 클래스룸에 그대로 올립니다.
  - 특정 차시 바로 열기: index.html#s4 (1~10차시는 #s1 ~ #s10, 교사 안내는 #guide)
  - 상단 '교사용' 버튼: 분 단위 진행표, 교사 팁, 학습지 정답이 추가로 표시됩니다.
  - OX 퀴즈: 차시마다 10문항. 문항 수(5·7·10)와 순서 섞기를 고를 수 있습니다.
  - 학습지 인쇄: 각 차시 끝의 '학습지만 인쇄' 또는 '차시 전체 인쇄'. 교사용 보기 상태에서 인쇄하면 정답 포함.
    (웹 미리보기 프레임 안에서는 브라우저 제한으로 인쇄가 안 됩니다. 파일을 직접 열어 인쇄하세요.)
  - 인터넷이 없어도 동작합니다. 글꼴만 온라인에서 불러오며, 없으면 시스템 글꼴을 씁니다.

수정·재생성
  parts/ 폴더의 조각 파일을 고친 뒤  python build.py  를 실행하면 index.html과 학습지모음.html이 다시 만들어집니다.
  index.html만 직접 편집해도 됩니다. OX 문항은 파일 끝 OX_DATA 블록에 모여 있습니다.

  - 법령 개정 여부: 국가법령정보센터 law.go.kr
